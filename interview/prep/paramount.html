Lambda vs ECS Fargate?

  • Lambda: short-lived, spiky, event-triggered (S3, API Gateway, SQS); low ops; pay per invoke; OK with cold starts
  • Fargate: long-running APIs, WebSockets, sustained traffic, custom deps, cold-start intolerance
  • Hybrid: API on Fargate, async workers on Lambda

Polish: Fargate = long-running / always-on (APIs, WebSockets). Lambda = cost-efficient for sporadic, event-driven work. Hybrid: API on Fargate, async workers on Lambda.

Problem 2 — merge intervals (pseudocode)

function merge(intervals):
    if intervals is empty: return []

    sort intervals by start
    merged = [copy of intervals[0]]
    for each [start, end] in intervals[1:]:
        last = merged[-1]
        if start <= last.end:          # overlap or touch
            last.end = max(last.end, end)
        else:
            merged.append([start, end])
    return merged

O(n log n) sort + O(n) scan. Edge cases: empty, single interval, one nested inside another.

def top_k_frequent(ids, k):

Problem 1 — LRU cache (common mistakes)

LRU: evict least recently used — track recency order in OrderedDict (move_to_end, popitem(last=False)).

from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity):
        self.cap = capacity
        self.cache = OrderedDict()

    def get(self, key):
        if key not in self.cache:
            return None
        self.cache.move_to_end(key)   # mark recently used
        return self.cache[key]

    def put(self, key, value):
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.cap:
            self.cache.popitem(last=False)  # evict oldest (LRU)

Trace cap=2: put(a,1), put(b,2), get(a), put(c,3) → evicts b (not used since a was touched).

Problem 5 — sliding window rate limiter

class SlidingWindowRateLimiter:
    def __init__(self, limit, window_sec):
        self.limit = limit
        self.window_sec = window_sec
        self._hits = defaultdict(list)  # partner_id → timestamps

    def allow(self, partner_id, now=None):
        now = now or time.time()
        cutoff = now - self.window_sec
        hits = [t for t in self._hits[partner_id] if t > cutoff]
        if len(hits) >= self.limit:
            self._hits[partner_id] = hits
            return False
        hits.append(now)
        self._hits[partner_id] = hits
        return True

Say: Per partner, prune hits older than window; if count ≥ limit return False, else append timestamp and return True.
