Scenario Questions (STAR Answers)

1. Database & ORM Bottlenecks

Q: Django API endpoint takes 4+ seconds listing orders with user profiles and items. Diagnose and fix?

  • Diagnose: Django Debug Toolbar / Datadog APM → N+1 query problem.
  • Fix: select_related() (FK/OneToOne), prefetch_related() (M2M/reverse), defer()/only() for heavy fields.
  • Result: 501 queries → 2 queries; ~4s → ~150ms.

2. ECS Fargate Crash Loop

Q: ECS task keeps crashing and restarting. Troubleshoot?

  • Diagnose: Exit 137 = OOM; Exit 1/127 = app crash (bad deps, DB connection, entrypoint).
  • Action: CloudWatch Logs → Secrets Manager / SSM → health check grace periods.
  • Result: Failing startup migration; moved to init container; increased memory limit.

3. External API Rate Limits

Q: Third-party API allows 100 req/min; your traffic needs 1,000/min.

  • Celery + Redis/SQS async queue; rate_limit on workers; Redis cache with TTL.
  • Result: No 429 errors; spike traffic smoothed.

4. Zero-Downtime Column Rename

  • Phase 1: Add new column, dual-write both.
  • Phase 2: Backfill with bulk_update() / iterator().
  • Phase 3: Read new only → drop old column.

5. Python Memory Leak in Celery Worker

  • tracemalloc / memory_profiler; check DEBUG=False; use .iterator() not list(qs); worker_max_tasks_per_child.

6. DB at 98% CPU During Peak

  • Short-term: RDS read replicas, Redis/ElastiCache, @cache_page.
  • Long-term: PgBouncer, composite indexes, ECS auto-scaling on ALB metrics.

7. Securing Django REST on AWS

  • JWT (simplejwt), DRF permission_classes, Secrets Manager, IAM task roles (taskRoleArn).

8. FastAPI vs Django

  • FastAPI: high-concurrency I/O (WebSockets, many concurrent HTTP calls).
  • Django: mature ORM, admin, auth, migrations for data-heavy apps.
  • Sync in async loop: sync_to_async() or Django async ORM (aget()).

9. Bad Deploy Broke Production

  • Rollback ECS task definition → revert Git → add pytest/ruff/mypy CI gates → blue/green deploys.

10. Legacy Django Monolith, No Tests

  • Baseline with ruff/mypy/Sentry → pytest integration tests on critical flows → strangler fig extraction.
